# Task 4 – Quiz Application

## Project Overview
This directory contains the completed **Task 4 (Medium) – Quiz Application** for the AUSPIFY Internship.

The application is built with modern **HTML5**, **CSS3**, and **Vanilla JavaScript** without any external runtime frameworks.

## Directory Structure
- [`quiz-app/`](./quiz-app/)
  - [`index.html`](./quiz-app/index.html) — Application markup and structure
  - [`style.css`](./quiz-app/style.css) — Styling, glassmorphic dark theme, animations, and responsive layouts
  - [`script.js`](./quiz-app/script.js) — Questions dataset, countdown timer, scoring engine, and navigation logic
  - [`README.md`](./quiz-app/README.md) — Comprehensive guide, testing checklist, and run instructions
- [`index.html`](./index.html) — Quick launcher redirecting directly into the quiz application

## Running the Application
Run a local static server inside this directory:
```bash
python -m http.server 8084
```
Then visit [http://localhost:8084/](http://localhost:8084/) in your browser.
